# Fable 5.1 と 5.2 を同じ課題で比べた記録

Claudeの新モデル「Fable 5.2」と、前のモデル「Fable 5.1」に、同じ指示文を渡して、出来を比べた記録です。note記事の実物を、手元で試せるようにしています。

- 条件:同じ指示文、ツールなし、1発生成、各2回、設定は既定
- 実施日:2026年11月10日
- 数字は [results.md](results.md) にあります

## 遊べるページ
GitHub Pagesで公開すると、次のページから、ブラウザで開けます。

## マリオ風ゲームの操作
矢印キーで移動し、スペースかZキーでジャンプします。長押しすると高く跳べます。

## バグ修正を試す
```
cd bugfix
python3 run_tests.py            # 最初は1/8
cp fixes/fable-5-2_run1.cart.py cart.py
python3 run_tests.py            # 8/8
```
`cart.py` は、試す前に元のものを控えておいてください。

## 注意
- 画像や指示文は、すべてAIに作らせたものです。マリオ風のゲームは、図形だけで作った別物です。任天堂とは関係ありません。
- 1回ずつの測定です。統計的な結論は出せません。
